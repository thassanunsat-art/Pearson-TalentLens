## ขั้นตอนเดโม (6 นาที)

1. เปิด `streamlit run app.py` เลือกตำแหน่ง **นักวิเคราะห์ข้อมูล** ชี้ให้เห็นเกณฑ์ must/nice และน้ำหนักที่ปรับได้
2. เลือก "ใช้ CV ตัวอย่าง" 8 ฉบับ (มีทั้ง PDF, DOCX และภาพสแกน) แล้วกด **คัดกรอง**
3. ชี้ตารางอันดับ: คะแนนรวม, ผ่านเกณฑ์บังคับหรือไม่, ข้อควรตรวจ
4. เปิดผู้สมัครอันดับ 1: แสดง quote หลักฐานของแต่ละเกณฑ์ และกรณีที่ระบบเข้าใจคำพ้อง (เช่น "pandas" → Python)
5. เปิดผู้สมัครที่มีธงเตือน: อธิบายว่าระบบตัดคะแนนเมื่อหลักฐานไม่พบใน CV
6. เปิด "ข้อความที่ส่งให้โมเดลให้คะแนน" เพื่อแสดงว่าชื่อ เพศ อายุ ถูกปิดแล้ว
7. บันทึกการตัดสิน "ผ่าน" พร้อมเหตุผล → เปิด audit log → ดาวน์โหลด Excel
8. (ถ้ามีเวลา) สลับเป็นโหมด rule-based เพื่อให้เห็นว่าอ่านภาพสแกนไม่ได้และพลาดคำพ้อง
